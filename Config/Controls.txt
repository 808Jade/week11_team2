DEVIL DUEL — 조작 방법

W / S       상대에게 접근 / 뒤로 이동하며 가드
A / D       상대 기준 좌우 횡이동
Shift       가드 유지
Space       백대시

J           잽
K           후크
U           몸통 킥
I           회전 킥
W + K       어퍼컷 · 공중 띄우기
W + U       무릎 공격
W + I       전진 점프 킥
S + K       팔꿈치 공격
S + I       드롭 킥

연속기
J → J → K        잽 → 스트레이트 → 후크
J → K → I        잽 → 후크 → 회전 마무리
U → U → K        몸통 킥 → 무릎 → 팔꿈치
W+K → J → I      어퍼컷 → 공중 잽 → 회전 마무리

각 버튼은 한 번씩 떼었다 다시 누릅니다.
공격이 맞거나 가드된 뒤 다음 입력을 미리 넣으면 연계합니다.
추가 입력이 없으면 공격의 복귀 동작까지 재생합니다.
공격을 빗맞히면 후딜레이가 끝날 때까지 행동할 수 없습니다.

R           경기 전체 재시작 · 재대전
P           일시정지 / 재개
T           CPU / 연습 상대 전환 (HUD의 CPU / P2로 구분)
Esc         게임 종료

60초 라운드, 2선승제입니다.
가드는 정면 공격을 막고 가드 게이지를 사용합니다.
가드 게이지가 소진되면 가드가 깨집니다.
어퍼컷으로 띄운 상대에게 추가 공격을 연결할 수 있습니다.
횡이동은 펀치를 피하는 데, 회전 공격은 횡이동을 잡는 데 유리합니다.

명중 순간 양쪽 캐릭터와 전투 시간이 완전히 멈추는 히트스톱이 적용됩니다.
약공격 0.11초, 강공격 0.17초, 띄우기 0.185초, 카운터 0.21초,
가드 브레이크 0.23초, KO 0.28초이며 가드는 0.06초 정지합니다.
정지 중에도 후속 공격 입력은 버퍼에 저장되며 카메라 연출은 계속됩니다.
KO는 정지 뒤 슬로모션으로 이어집니다.
체력 아래의 작은 선은 가드 게이지, 작은 점등 표시는 라운드 승리입니다.
