# Devil Duel

기존 데빌진 캐릭터와 격투 애니메이션으로 구성한 1인용 3D 대전 게임입니다. 플레이어와 CPU가 60초 라운드, 2선승제로 대전합니다.

## 실행

저장소 루트의 `PlayDevilDuel.bat`을 실행합니다. 다시 빌드하려면 `PlayDevilDuel.bat -Build`를 실행합니다. 에디터에서는 `Scenes/DevilDuel.scene`를 열고 Play를 누릅니다.

전용 실행기는 `HitoriGame.exe -Map=Scenes/DevilDuel.scene`를 사용합니다. `Config/DefaultGame.ini`의 기본 시작 맵도 `Scenes/DevilDuel.scene`으로 설정되어 있어 에디터의 Package Game 또는 `Package.bat Release`로 내보낸 실행 파일에서도 이 게임이 시작됩니다. 패키지 위치는 `Build/Package/Hitori/HitoriGame.exe`입니다.

## 조작

배포 폴더의 `Controls.txt`에 조작과 연속기 설명을 함께 제공합니다. 게임 화면에는 키 설명, 공격 이름, 상태 문자열과 콤보 수치를 표시하지 않습니다.

| 키 | 동작 |
|---|---|
| W / S | 상대에게 접근 / 뒤로 이동하며 가드 |
| A / D | 상대 기준 좌우 횡이동 |
| Shift | 가드 유지 |
| Space | 짧은 백대시 |
| J | 잽 |
| K | 후크 |
| U | 몸통 킥 |
| I | 회전 킥 |
| W + K | 띄우는 어퍼컷 |
| W + U | 무릎 공격 |
| W + I | 전진 점프 킥 |
| S + K | 팔꿈치 공격 |
| S + I | 드롭 킥 |
| R | 경기 전체 재시작 |
| P | 일시정지 |
| T | CPU / 가만히 서 있는 연습 상대 전환 |

## 전투

상대와의 거리를 좁히고 공격합니다. 공격 방향은 시작 시 고정됩니다. 좁은 펀치는 횡이동으로 피하기 쉽고, 넓은 회전 킥은 횡이동을 잡는 데 유리합니다. 빗나간 공격의 후딜레이를 노리면 반격할 수 있습니다.

가드는 정면 공격을 흡수합니다. 가드 게이지가 소진되면 가드가 깨지고 잠시 무방비 상태가 됩니다. 공격이나 피격 중에는 가드할 수 없습니다. 게이지는 일정 시간 공격을 받지 않으면 회복합니다.

연속기는 공격이 명중하거나 가드된 뒤 다음 버튼을 입력하면 이어집니다. 공격 도중 다음 입력 하나를 미리 받아 두는 버퍼가 있습니다.

| 입력 | 연계 |
|---|---|
| J → J → K | 잽 → 스트레이트 → 후크 |
| J → K → I | 잽 → 후크 → 회전 마무리 |
| U → U → K | 몸통 킥 → 무릎 → 팔꿈치 |
| W+K → J → I | 어퍼컷 → 공중 잽 → 회전 마무리 |

후속 입력마다 키를 한 번씩 떼었다 누릅니다. 떠 있는 상대에게 추가 타격을 넣을 수 있으며, 연속 타격이 늘수록 피해가 감소하고 최대 공중 연계 후에는 다운됩니다. 다운과 기상 중에는 추가 공격을 받지 않습니다.

CPU는 거리 조절, 공격 선택, 가드, 횡이동, 짧은 연속기를 사용합니다. 공격 준비를 본 뒤 일정 간격으로 반응하므로 모든 공격을 즉시 읽거나 방어하지는 않습니다.

## 구성과 검증

`Scripts/devil_duel_rules.lua`는 고정 간격 전투 시뮬레이션, 입력 버퍼, 가드, 공격 범위, 피해, 넉백, 띄우기, CPU와 라운드 규칙을 담당합니다. `Scripts/devil_duel.lua`는 엔진 입력, 실제 애니메이션, 카메라, 효과음과 HUD를 연결합니다. `Scripts/devil_duel_clips.lua`는 루트 이동을 추출해 다시 구운 애니메이션의 경로와 길이입니다.

`Motion/`의 21개 클립은 기존 원본 FBX를 같은 Devil Jin 스켈레톤에 리타게팅하면서 루트 이동을 추출한 복사본입니다. `Scripts/CookDevilDuelMotion.ps1`로 재생성합니다. 네이티브 애니메이션이 추출한 월드 이동을 Lua 컨트롤러에서 소비한 뒤 캐릭터 간 거리와 무대 경계를 적용합니다. 이동과 공격을 별도의 일정 속도로 전진시키던 방식은 루트 모션 모드에서 사용하지 않습니다. 원본의 회전 동작은 포즈에 유지하고 대전 방향은 게임 규칙에서 관리합니다.

기술별 시작 구간·재생 속도·접촉 시점을 조절하고, 종료는 원본 클립의 마지막 프레임까지 유지합니다. 공격 시간이 지나도 네이티브 재생 완료가 확인되어야 대기 자세로 돌아갑니다. 후속 공격을 입력한 연계와 피격은 동작을 중단할 수 있습니다. 준비 자세·몸통 및 머리 피격·가드 반응·다운·기상도 구분합니다. 전진 스텝은 1.10배속, 후퇴는 0.95배속, 횡이동은 1.05배속으로 재생해 빠른 반복을 줄였습니다. 전진 클립의 시작과 끝에 있던 약 6.7cm 골반 높이 차이는 쿠킹할 때 보정해 반복 경계의 수직 튐을 줄였습니다.

카메라는 기존 `APlayerCameraManager`를 통해 FOV Punch와 Camera Shake 모디파이어를 사용합니다. 명중·카운터·강한 공격·가드에 서로 다른 히트스톱과 진동을 적용하고, KO 때는 정지 후 슬로모션으로 이어집니다. 카메라 모디파이어와 HUD 잔상은 실제 시간으로 진행하므로 히트스톱 중에도 연출이 동작합니다. 준비와 라운드 종료에는 짧은 레터박스를 사용합니다.

타격 줌은 약공격 3.2도, 강공격 7.5도, KO 10도이며, 회전과 위치 진동을 함께 적용합니다. 에디터에서도 같은 Lua와 네이티브 카메라 매니저 경로를 사용합니다. 엔진 코드를 변경한 뒤에는 실행 중인 에디터를 종료하고 해당 구성의 에디터를 다시 빌드해야 합니다. `Scripts/TestDevilDuel.ps1 -Configuration Debug`는 Debug 빌드와 PIE 복제 월드의 실제 입력·카메라·HUD 동작을 검사합니다.

HUD는 체력·가드·타이머·라운드 승리 표시를 중심으로 구성했습니다. 체력은 양쪽 바가 서로 반대 방향으로 감소하고, 피해 잔상과 피격 플래시 및 저체력 표시를 사용합니다. 준비·승패·일시정지 메시지만 중앙에 표시합니다. `node Scripts/BuildDevilDuelHUD.mjs`로 위젯 에셋을 다시 생성할 수 있습니다.

`AS_GetUp.fbxbin`은 기존 Standing Up 클립의 골반 높이를 보정한 복사본입니다. 기상 마지막 자세와 격투 대기 자세의 높이를 맞춥니다. 원본 클립은 보존하며, `Scripts/BuildDevilDuelGetUp.ps1`로 복사본을 다시 생성할 수 있습니다.

공격은 상대 방향을 기준으로 한 평면 범위 판정을 사용합니다. 뒤로 이동과 오른쪽 횡이동은 기존 이동 클립을 역재생하고, 가드는 격투 대기 동작의 재생 속도를 낮춰 구성합니다. 상단·중단·하단 구분, 손발 본에 붙는 개별 충돌 도형, 네트워크 대전은 포함하지 않습니다.

## 네온 골목

기존 링은 Poly Haven의 건물·셔터·배관·전선·실외기·가로등·쓰레기통·봉투·상자 모델로 교체했습니다. 35개 메시를 403회 배치하고, 내려받은 아스팔트·콘크리트 텍스처, 입체 네온 간판과 조명을 연결했습니다. 출처와 라이선스는 [Environment/CREDITS.md](Environment/CREDITS.md)에 있습니다. `Environment/Models/`와 `Environment/Textures/`는 이미 포함되어 있어 플레이할 때 인터넷이나 Blender가 필요하지 않습니다.

배경을 재생성할 때는 순서대로 실행합니다. Node.js와 Blender 5.2가 필요합니다.

```powershell
node Scripts/FetchDevilDuelEnvironment.mjs
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --factory-startup --python Scripts/BuildDevilDuelEnvironment.py
node Scripts/BuildDevilDuelScene.mjs
```

원본 다운로드는 `Build/DevilDuelSources/`에 보관하고 체크섬을 확인합니다. 변환기는 엔진의 좌표계·삼각형 방향·재질 슬롯에 맞춰 사용 중인 부품만 내보냅니다.

`powershell -ExecutionPolicy Bypass -File Scripts/TestDevilDuel.ps1`로 전투 규칙과 실제 Lua 입력, 배경 메시 로드, 루트 이동 소비·직접 적용, 11개 기술, 애니메이션 전환 및 HUD를 검사합니다. 실제 엔진으로 렌더링한 캡처는 `Build/DevilDuelTests/`에 저장합니다.
